# Conversion Project

A Node.js conversion API that allows users to perform different types of unit conversions.

# Features

- User registration and login
- Session-based authentication
- Unit conversion
- Conversion history
- Password hashing using bcrypt
- Middleware for authentication
- Layered project architecture
- JSON-based data storage

# Technologies Used

- Node.js
- Express.js
- JavaScript
- bcrypt
- express-session
- REST API
- Postman
